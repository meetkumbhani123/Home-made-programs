# Home-made Programs

A collection of basic programming exercises and examples in C and HTML.

## Contents

### C Programs

1. **multiplicationtable.c** - Multiplication Table Generator
   - Prompts user for a number and displays its multiplication table (1-10)
   - Demonstrates: loops, input/output, basic arithmetic

2. **pattern1.c** - Character Pattern Printer
   - Prints a 5x5 pattern using characters A-E
   - Demonstrates: nested loops, character manipulation

### HTML Files

3. **lab3c.html** - Table Layout Example
   - Demonstrates various HTML table features including colspan, rowspan
   - Shows table structure for what appears to be an invoice or form layout

### Other Files

4. **Python Programming - Lab - 5.ipynb.url** - URL shortcut file (empty)

## How to Use

### Compiling C Programs

Make sure you have GCC installed, then compile the programs:

```bash
# Compile multiplication table program
gcc -o multiplicationtable multiplicationtable.c

# Compile pattern program  
gcc -o pattern1 pattern1.c
```

### Running C Programs

```bash
# Run multiplication table program
./multiplicationtable

# Run pattern program
./pattern1
```

### Viewing HTML Files

Open the HTML files in any web browser to see the table layouts.
